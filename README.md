## 📌 Deliverable Overview
- **Validation Utility**: [`../client/src/utils/validation.js`](../client/src/utils/validation.js)
- **Validation Rules**:
  - `validateEmail`: Standard RFC-compliant email regex format.
  - `validatePassword`: Minimum 8 characters with required alphanumeric mixture.
  - `validateRequired`: Non-empty, trimmed string enforcement.
  - `validateLength`: Minimum and maximum string bounds.
  - `validatePasswordMatch`: Password confirmation verification.
- **Consumer Forms**: Integrated into `Login.jsx`, `Signup.jsx`, `CreatePostForm.jsx`, `EditPostForm.jsx`.
